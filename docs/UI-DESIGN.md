# Interface direction: warm, understated matchmaking

The user selected ivory, plum and editorial typography. The workspace serves a matchmaker reviewing people, their preferences and the reasons an introduction may be worthwhile. It should feel personal and considered, with the clarity of an internal operations tool.

## Tokens

- Ivory canvas: `#f7f4f0`
- Paper surface: `#fffdfb`
- Plum action: `#624458`
- Primary ink: `#342b33`
- Secondary ink: `#786e75`
- Warm border: `#e6dfda`

Newsreader gives page headings and profile names a restrained editorial character. DM Sans handles body copy, controls and data. Main content is 14px, primary table data 13px, and supporting information never below 11px. Dark plum actions and clearly distinguished journey tags carry the interaction hierarchy.

## Layout and signature

The dashboard keeps customer management central: a useful summary, visible search and filters, and a readable table with initials, customer names and explicit profile links. No decorative hero, promotional sidebar card or icon statistics.

The signature is a customer brief directly above the shortlist. It gives children, relocation, pets and marriage timeline a visible place in the review, connecting the design to the matching logic. Candidate cards use a deliberate reading order: person, mutual fit, factual reasons, discussion point and introduction action.

```text
Navigation | Customers                              Browse candidates
           | Assigned / Ready for review / Introductions / Verification
           | Customer search + journey filters
           | Person | Age | City | Marital status | Verification | Stage

Navigation | Customer name + career                   Journey stage
           | Children / Relocation / Pets / Marriage timeline
           | Profile / Suggested matches / Notes & activity
           | Candidate + mutual fit | Candidate + mutual fit
           | Compatibility reasons | Compatibility reasons
           | Biodata / Draft intro  | Biodata / Draft intro
```

Draft introduction opens an editable preview with a prominent Generate with Gemini action. Matchmaking decisions and sending remain with the matchmaker. Real AI and template states remain visibly distinct.

## Critique

The earlier revision stripped away too much personality and made profile review resemble a generic database console. Returning only to the original lavender cards would repeat its weak hierarchy. This revision uses the user's chosen palette and typography, but changes the information structure: the customer brief and candidate evidence create the warmth and purpose, without hearts, sparkles, circular gauges or inspirational filler.
